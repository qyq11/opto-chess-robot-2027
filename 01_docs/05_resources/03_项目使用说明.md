# 项目使用说明

更新日期：2026-11-07。从根目录 README 整理迁入获取项目、目录和运行方法，方便首页集中展示硬件外形与简短进度。任务与完成标准仍在[开发计划](../01_plans/01_开发计划.md)维护，实验过程继续更新各自的原记录。

## 获取项目

需要 [Git](https://git-scm.com/)。网页运动的回退压缩包通过 [Git LFS](https://git-lfs.com/) 保存；需要这些文件时，先安装 Git LFS，再初始化支持：

```sh
git lfs install
```

下载仓库：

```sh
git clone https://github.com/qyq11/opto-chess-robot-2027.git
```

进入项目根目录，后续命令均在这里执行：

```sh
cd opto-chess-robot-2027
```

已有仓库而尚未下载回退包时，可补取 Git LFS 文件：

```sh
git lfs pull
```

直接阅读 Markdown、PDF 和结果图片不需要连接机器人。机器人运行、模型编辑和文档网站各自使用的环境见下文。

## 运行算法示例

需要 [Python](https://www.python.org/downloads/)：透视变换示例要求 3.10 或更新版本，象棋识别要求 3.11 或更新版本。依赖、输入、输出和验证范围见各自记录。

安装透视变换示例依赖：

```sh
python -m pip install -r 02_programs/01_host/01_perspective/requirements.txt
```

运行默认样图：

```sh
python -X utf8 -B 02_programs/01_host/01_perspective/perspective_demo.py
```

运行后会打印四点坐标、变换矩阵和图内误差，并保存标注图、俯视图、对比图和结果数据。输入照片、参数用法与误差含义见[透视变换记录](../03_records/01_20261023_透视变换.md#运行方法)。

象棋识别的安装、完整命令、模型许可和中文字体要求见[运行与复核](../03_records/02_20261023_象棋识别.md#5-运行与复核)。已有两张真实照片、12 个人工选定区域的离线结果，以及低机位生成图演示；这些结果不代表全图自动找棋子或车载比赛场景已验收。

## 连接小车工作台

板 B 已配置自动连接电脑热点 `opto-robot-b`。电脑与板卡连接后，使用浏览器打开[小车工作台](http://192.168.137.16:8080/)；这是 2026-11-05 保存的热点地址，地址变化时以电脑热点的已连接设备列表为准。该地址是局域网入口，不能从公网直接访问。

网页提供相机预览、拍照和四向控制。连接步骤及原始图像证据见[无线相机记录](../03_records/05_20261103_相机采集与电脑预览.md#wireless-camera-20261105)，运动参数、方向与停止操作见[网页运动说明](../02_design/05_底盘串口接线与测试.md#web-motion)。

RK 程序的编译、上传和实际运行方法见[相机记录](../03_records/05_20261103_相机采集与电脑预览.md)及[底盘记录](../03_records/04_20261030_底盘串口调试.md)。定距离首版仍待板端检查和地面尺测，任务统一在[开发计划](../01_plans/01_开发计划.md#distance-first-run)维护。

## 打开文档网站

需要 [Node.js 20 或更新版本](https://nodejs.org/)及其附带的 npm。先确认版本：

```sh
node --version
```

首次安装网站依赖：

```sh
npm --prefix 06_website run setup
```

启动本地开发服务：

```sh
npm --prefix 06_website run start
```

浏览器打开 [localhost:3000](http://localhost:3000/)，首页为开发计划，左侧可浏览方案、记录、会议和资料；本说明位于“05 资料”。编辑 `01_docs/` 中的 Markdown 即可更新内容，停止服务使用 `Ctrl+C`。

构建静态网站并检查链接：

```sh
npm --prefix 06_website run build
```

预览构建结果：

```sh
npm --prefix 06_website run serve
```

网站依赖、缓存和构建结果统一由 `06_website/run.mjs` 写入 `temp/docusaurus/`，静态网站位于 `temp/docusaurus/build/`。清理该目录后可重新安装、构建；文档源与网站配置保存在正式目录。当前网站用于本地阅读，未配置线上发布。

网站构建和资料检查只说明电脑上的文档可以生成、链接有效，不代表 RK 板端或实车功能通过。历史清理的范围、留存文件及检查结果继续见[同一份整理记录](../03_records/03_20261024_机械装配验证.md#2026-11-06-缓存与中间文件清理)。
