## 地址问题与修正

原配置让驱动在 `0x37` 查找相机，启动时未读到有效识别值。16:15在供电、复位和输入时钟有效的条件下，实际查到相机位于I²C4总线的7位地址 `0x1a`，读取检查寄存器 `0x311a` 得到 `0xe0`，符合当前驱动判据。诊断结束后已恢复相关资源并卸载临时模块。

用户授权后，采用官方支持的[启动配置插件方式](https://wiki.lckfb.com/zh-hans/tspi-3-rk3576/sys-tool/ovtree.html)修正地址：

- 新增 `lckfb-imx415-i2c4-1a.dtbo`，把I²C4下IMX415的 `reg` 地址从 `0x37` 改为 `0x1a`，并禁用同一接口上备用的GC05A2节点。
- 原IMX415节点名 `imx415@37` 保留，以保持原有连接关系；实际通信地址由 `reg` 属性决定。
- 原已启用的CAN、串口插件保留。未替换内核或系统镜像；重启后配置生效。

16:27重启后的正式驱动日志：

```text
imx415 4-001a: Detected imx415 id 0000e0
```

同时确认 `/sys/bus/i2c/drivers/imx415/4-001a` 已绑定，采集入口为 `/dev/video-camera0`，指向 `/dev/video33`。其余未接相机的接口仍有探测失败日志，与本次已连接相机的识别结果分别判断。

原始终端返回分别保留：[14:53修正前的失败结果](../../05_data/01_raw/04_hardware/20261103_camera_before_fix_01.txt)、[插件部署结果](../../05_data/01_raw/04_hardware/20261103_camera_overlay_deploy_01.txt)、[16:27重启后正式驱动识别结果](../../05_data/01_raw/04_hardware/20261103_camera_driver_check_01.txt)。三份文件均按原字节归档；修正前失败结果不记作修正后复测，也不把这些日志作为两轮采图的证明。

配置源码：[相机地址插件](../../02_programs/01_host/03_camera/config/lckfb-imx415-i2c4-1a.dts)。修改前后的启动配置、部署文件及SHA-256指纹见[配置备份清单](../../07_backups/01_相机地址/sources.json)。需要回退时，将清单中两份 `before` 文件恢复到各自的板端路径，再重启，恢复原插件列表。

## 拍照与电脑取图结果

| 核对项 | 实际结果 |
| --- | --- |
| 采集方式 | 板端已有GStreamer工具，从 `/dev/video-camera0` 取帧并编码为JPEG |
| 图像参数 | NV12，1280×720，协商帧率30帧/秒，JPEG质量95 |
| 第一轮，16:28 | 连续取得60帧，约2.25秒结束；电脑打开后画面明显模糊 |
| 第二轮，16:30 | 用户重新朝向远处物体后，再次取得60帧，约2.27秒结束；电脑可见桌面、显示器和线材等现场内容，画面与第一轮不同 |
| 停止再开 | 第一轮结束后可再次启动采集，两次均正常结束 |
| 传回电脑 | 经有线SSH执行采集，SCP取回照片；文件指纹一致，电脑实际打开检查 |

本次使用的第一轮采集命令如下；其中输出目录是已清理的临时测试目录：

```bash
timeout --signal=INT --kill-after=5s 20s gst-launch-1.0 -e v4l2src device=/dev/video-camera0 io-mode=mmap num-buffers=60 ! video/x-raw,format=NV12,width=1280,height=720,framerate=30/1 ! jpegenc quality=95 ! multifilesink location=/tmp/codex-camera-capture-20261103/frame-%03d.jpg max-files=3
```

## 上电配置核对

已对照[IMX415芯片手册](../../04_references/04_datasheets/03_IMX415-AAQR-C_Datasheet.pdf)第14、84～86页核查：配置供电为2.8V、1.8V、1.2V，处于手册规定范围；输入时钟为37.125MHz，复位为低电平有效，供电常开且共用使能脚。配置值核对不等于芯片端电压和时序波形实测，本次未进行示波器测量。

商家发来的图是第86页的**下电时序**，规定三路电源和控制信号关断的先后关系；上电时序在第84～85页。用户原始资料及来源见[接线照片](../../05_data/01_raw/04_hardware/20261103_camera_connection_01.jpg)、[商家时序截图](../../05_data/01_raw/04_hardware/20261103_camera_poweroff_sequence_01.png)和[来源清单](../../05_data/01_raw/04_hardware/sources.json)。
