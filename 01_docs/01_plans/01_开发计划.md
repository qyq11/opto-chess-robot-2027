### 3. Python 透视变换研究与项目相机复核

目标：将斜视图中的目标平面校正为俯视图，用可复现的 Python 程序展示结果。

- [x] 使用 OpenCV 官方实拍棋盘图，保留原图；确定四组对应点与 5:8 的目标坐标跨度，输出 501×801 像素。
- [x] 学习透视变换与平面单应的适用条件，核对点序和坐标定义；明确本例未去畸变，项目相机应用需先标定与校正。
- [x] 使用 Python 完成图像读取、对应点配置、变换和结果保存，写明依赖及运行方法；支持自动棋盘和手动四点两种输入方式。
- [x] 保存原图、对应点标注图、俯视结果和对比图；记录 50 个非拟合角点的误差，正式源码与结果已归档并回填会议纪要。
- [ ] 使用项目相机采集不同拍摄角度的真实平面图像，标定/去畸变后复核，记录失败情况与实际位置误差，追加到[既有研究记录](../03_records/01_20261023_透视变换.md)。

**当前结果：** 单图程序、对比图和同图检查点残差已完成，见[记录](../03_records/01_20261023_透视变换.md)。**下一步：** 采集项目相机图像并标定/去畸变，复核多个角度的效果。**后续完成标准：** 在实际相机与已知平面尺寸下可复现，用未参与求解的实测检查点记录位置误差；面向机器人定位的精度门槛待后续需求确定，不将官方样图演示当作实车验证。

已实现路线：使用 Python + OpenCV，通过 `cv2.getPerspectiveTransform` 根据四组对应点求变换矩阵，再用 `cv2.warpPerspective` 生成图像，见 [OpenCV 官方几何变换文档](https://docs.opencv.org/4.x/da/d54/group__imgproc__transform.html)。当前完成的是电脑上的单图示例。

研究边界：俯视校正针对选定平面，不能恢复被遮挡的内容；地面和有高度的棋子顶面需区分处理，见 [OpenCV 单应教程](https://docs.opencv.org/4.x/d9/dab/tutorial_homography.html)及[既有方案中的定位说明](../02_design/02_四种方案.md#四种方案共用的智能化闭环)。
